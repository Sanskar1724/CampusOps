# Features

## 🧠 One Core Agent, every channel
Single `handle_turn()` serves web chat, Telegram, email, and scheduled jobs.
Tool-using: timetable, deadlines, exams, email search, document search, memory,
tasks, reminders, daily plan, urgency-ranked focus. Retrieval-first, cited
sources, untrusted-input guards.

## 💬 Chat that manages your timetable
Hide/show/delete by conversation (`hide OS`, `don't show Saturdays`,
`show everything`, `what did I hide`, `delete Physics class`). Hiding is
per-student and view-only; whole-class data stays intact.

## 🗓️ Timetable, your way
My-classes (Div/Batch) default + whole-class toggle; manual form, CSV/JSON,
paste-text, PDF/photo scan with batch-cell splitting and OCR retry.

## 📧 Email intelligence
Gmail OAuth (read-only, auto token refresh), 10-kind classification, date/room/
subject extraction, relevance filter, auto-created deadlines/exams/
announcements, room-change conflict alerts.

## 📄 Documents that answer back
PDF/TXT/CSV/XLSX/DOCX/PNG/JPG → layout extraction → vision-OCR fallback for
scans → chunked hybrid search → per-item deadlines/exams. Re-scan with OCR.

## 🔔 Notifications with rules
Morning brief, due-soon deadlines, due reminders, change alerts — each
toggleable, with quiet hours and channel choice (auto/gateway/telegram).
Gateway-first delivery, Telegram fallback, honest statuses.

## 📱 Telegram bot (@Sankiyy_bot)
First-time guide, 7 quick-action buttons, 9 slash commands, onboarding in chat,
same brain as web.

## 🔌 Connection board + help
Settings shows every integration 🟢/🔴 with fixes; Help page serves the user
guide from the backend (single source shared with the agent).
